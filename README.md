# CloneReminder

CloneReminder is a study project focused on learning **SwiftUI** and **SwiftData** by building a simple reminders-style app.

## Goals
- Practice app architecture with SwiftUI (views, navigation, state management)
- Persist data locally using SwiftData (models, queries, CRUD)
- Explore common patterns like lists, filtering, and basic forms

## Requirements
- Xcode 15+ (Swift 5.9+)
- iOS 17+

## Getting started
1. Open `CloneReminder.xcodeproj` in Xcode.
2. Select an iOS Simulator or a connected device.
3. Run the `CloneReminder` scheme.
